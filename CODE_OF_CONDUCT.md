# Code Of Conduct

## Our Standard
We expect contributors and maintainers to participate in a respectful, professional, and constructive way.
This code of conduct applies to issues, pull requests, release discussions, and other public interactions in the GitHub repository.

## Expected Behavior
- Be respectful in communication.
- Assume good intent, but stay precise and factual.
- Accept feedback without personal attacks.
- Focus discussion on code, design, and user impact.

## Unacceptable Behavior
- Harassment, intimidation, or discrimination.
- Personal insults or abusive language.
- Publishing private information without permission.
- Deliberately disruptive behavior in issues, pull requests, or discussions.

## Enforcement
Project maintainers may remove comments, reject contributions, or restrict participation for behavior that violates this code of conduct.

## Reporting
Report serious conduct issues privately to the project maintainers through private repository or organization contact paths.
Do not use public issues for sensitive conduct reports.
